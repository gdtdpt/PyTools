# PyTools v2 重写验收矩阵

状态：**M0 产物，待用户确认**。来源：v1.8.1 实际行为 + `docs/v2-plan.md` 已拍板决策。
用法：每个里程碑开发前对照本矩阵核对该域条目；验收时逐条勾验。v2 中被否决/降级的条目在此显式标注，不允许静默消失。

## 1. 壳能力（M1）

| # | v1 行为 | v2 归属 | v2 验收标准 |
|---|---|---|---|
| S1 | 全局热键呼出/收起主窗（热键可配置） | M1 | 弱机呼出体感即时；耗时基线实测对比 v1 |
| S2 | 失焦自动隐藏 | M1 | 焦点离开即收起，不闪烁 |
| S3 | 置顶浮层、不占任务栏、窗口位置记忆 | M1 | 重启后位置恢复 |
| S4 | 托盘常驻 + 菜单（重新扫描、退出等） | M1 | 全部菜单项行为一致 |
| S5 | 单实例：二次启动唤起已有实例 | M1 | 二次启动不起新进程 |
| S6 | Esc 收起 | M1 | 任意状态下 Esc 语义与 v1 一致 |
| S7 | 图钉：钉住后失焦不隐藏、出现任务栏图标、可被遮挡；退出工具/再点/Esc 解除；不跨工具保留 | M5（v1 长尾） | 行为逐条对照 v1 |
| S8 | Win32 前台 capture/restore | M1 | **无 helper 进程**；恢复后采样验证 + 重试；目标机手工验收焦点恢复 |
| S9 | 剪贴板直呼热键 | M3 | 呼出 <100ms（44 图历史实测） |
| S10 | 开机自启动 | M2 | 注册表 Run 项写入/移除；**v1 缺陷（2026-11-04 实测）：Electron `setLoginItemSettings` 的 Run 键名含版本标识（`electron.app.pytools-1.6.0`），版本更迭后旧键删除不到、取消自启后仍残留自启旧包——v2 用固定键名 `PyTools` + 启动时清理非本键名的历史 PyTools 残留项** |
| S11 | 调试模式（禁失焦隐藏、便于检查） | M1 | `--debug` 保留；**新增：落盘运行日志**（v1 无日志导致 10-29 慢呼出无法回放的教训） |
| S12 | 主题令牌体系（theme.css） | M1 起步 | WPF ResourceDictionary 令牌层，对应 v1 design-system 六维度 |
| S13 | **简洁模式**（v2 新，2026-10-30 用户提议） | M1 | `v2.liteMode` 开关：不透明窗/方角/去动效，仅「窗口底、阴影、动效」三类令牌退化，布局/间距/字号/控件圆角与默认形态强制同值；两形态基线各测一组 |

## 2. 启动器（M2）

| # | v1 行为 | v2 归属 | v2 验收标准 |
|---|---|---|---|
| L1 | 应用扫描（配置目录 + `custom-apps.json` 合并，自定义优先） | M2 | 合并与优先级语义一致 |
| L2 | 搜索 + 结果列表 + 动态结果高度 | M2 | — |
| L3 | 应用启动：无参 openPath、带参 spawn（quote-aware 分词）；`isKnownApp` 授权语义 | M2 | 两条启动路径（回车 / Tab 菜单）行为统一——v1 教训 |
| L4 | 死条目：目标不存在 → 提示 + 自动移除登记；其他失败保留记录 | M2 | v1 1.8.1 行为逐条回归 |
| L5 | Tab 操作菜单 | M2 | — |
| L6 | **连续滚动列表**（v2 新）：滚轮/滚动条全量可达，Ctrl+J/K 逐条跟随，Ctrl+N/P 步进 N（可配默认 5），数字键 1-0 映射当前可视区 | M2 | 不再分页；角标锚定可视区，滚动后对可见行重编号（2026-10-30 用户验收定案：任意滚动位置每行都有号可按；首可见行判定按「露出 ≥60%」取真实容器索引，不按行高估算） |
| L7 | 拼音首字母搜索（v2 新，可选开关） | M2 | 内网脱机可用（本地实现，无网络） |
| L8 | 右键登记：HKCU 静态动词、开关默认关、点击即生效、lnk 解析真实路径 + args 留存、挪目录自愈 | M2 | 注册表行为与 v1 等价；`custom-apps.json` 格式沿用 |
| L9 | 静默添加：不弹主界面、托盘气泡反馈、冷启动静默驻留、`--add-app=<路径>` 自包含 token | M2 | v1 C 段验收 17-21 全部回归 |
| L10 | 设置窗口：热键配置、开机自启、右键菜单开关、清单管理（条数/清空/打开文件夹） | M2 | — |
