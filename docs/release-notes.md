# 发布说明

## 2.0.0（2026-11-17）

v2 重写的首个正式版（WPF / .NET Framework 4.6.2，单 exe）。此前 rc1–rc10 均为预发布包，rc1–rc10 已全部作废；正式版内容对应 rc10，并经双屏（混合 DPI）真机验证。

### 交付物

`dist/PyTools-2.0.0-win64.zip`（PyTools.exe 503 KB + README），解压即用，无需安装。

### 功能一览（相对 v1 Electron 版的完整重写）

- 启动器：应用扫描 + 拼音首字母搜索 + 连续滚动列表；Tab 操作菜单（八项动作）；Ctrl+K 动作面板；右键「添加到 PyTools」登记与自愈。
- 剪贴板历史：事件驱动监听，文本/图片/文件记录与写回、直呼热键、隐私过滤开关。
- 工具：text-diff、regex（含 AI 生成）、cron、encoding-converter、format、vsc、ai-ocr、ai-translate、code-naming。
- 外观：明暗主题三态热切换、简洁模式；呼出动画与固定尺寸模式。

### rc4–rc10 修复的多屏呼出定位（2.0.0 最终形态）

- 呼出窗跟随**鼠标所在屏**：位置记忆**每屏一份**（键 = 设备名@整屏物理尺寸，分辨率变化自动回默认位）；无记忆或横向越界走默认位（水平居中、垂直上 1/3）。
- 全程物理像素 + 逐屏 DPI（PerMonitorV2），混合 DPI 双屏（如 200% + 100%）下位置与物理尺寸均正确。
- 跨屏 DPI 切换时窗口尺寸连期望矩形一起钉回，杜绝副屏「窗口很小且不居中」。
- 落位日志 `summon place [default|memory|memory-oob->default] key=… work=… scale=… -> x,y w=…`，排障只看这一行。

### 其他修复

- 带参数的 .lnk 启动报「不是有效的 Win32 应用程序」（193）：改用解析后的真实目标启动。
- 简洁模式暗色主题整窗发白；多行编辑区滚动条贴底；截断文本 ToolTip 显示全文；剪贴板图片 alpha 无效修复等。

### 升级说明

- **从 v1（Electron 版）升级**：v2 使用 exe 同目录存放配置（`config.json`、`custom-apps.json` 等），把 exe 放入原 v1 目录即可继承应用登记数据；全局热键、单实例、右键菜单与 v1 互斥，切换前请退出 v1。
- **从 rc 预发布版升级**：直接替换 exe。旧的全局呼出偏移会被自动作废，首次呼出为默认居中位，在各屏拖动收起后重新建立每屏记忆。
