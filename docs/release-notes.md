# 发布说明

## 2.1.0（2026-11-19）

新增网页搜索：主搜索框可直接调用搜索引擎搜索、直达网址。真机验证通过。

### 新增

- **搜索引擎配置**（设置 → 搜索）：总开关默认关闭；预置 Google（别名 `g`）、百度（`bd`）、Bing（`bi`，默认停用），支持自定义新增引擎。
  - 每行可编辑名称 / 别名 / 搜索地址，勾选启用，单选默认引擎，× 删除（有确认框）。
  - 搜索地址用 `%s` 作搜索词占位符；**不含 `%s` 则回车直接打开该页面**（适合 DeepSeek 这类不支持 URL 带词的站点）。
  - 别名唯一性校验；未填完整的引擎行不参与触发。
- **别名前缀模式**（主力路径）：主搜索框输入「别名 + 空格」（如 `g 关键词`）进入该引擎搜索态——左侧徽章显示引擎名、列表收起，输入内容回车即用默认浏览器搜索并收窗。
  - 退出：Esc 回普通搜索（已输入内容保留）；输入为空时按一次 Backspace 退出。
- **引擎兜底条目**（辅助路径）：正常输入时列表末尾每个启用引擎各一条「用 X 搜索「输入内容」」；无匹配结果时该条目自动成为唯一条目并默认选中。
- **网址直开**：输入以 `http://` / `https://` 开头的网址，列表首位出现「用浏览器打开」并默认选中，回车原样打开。该功能不受搜索开关控制。
- 打开网页后浏览器保持前台（收窗时不恢复原前台窗口）；搜索地址配置非法时 toast 提示且不收窗。

### 升级说明

- **从 2.0.1 升级**：直接替换 exe，配置与数据（`config.json`、`custom-apps.json`、剪贴板历史等）不动。网页搜索默认关闭，需在设置 → 搜索中开启。

## 2.0.1（2026-11-19）

修复搜索/过滤输入框光标压住占位提示文字的问题。

### 修复

- **输入框光标压占位提示**：呼出窗主搜索「搜索应用…」与 Ctrl+K 动作面板「搜索操作…」等五处输入框，自动聚焦的空框光标落在占位文字首字上。两层根因，一并修复：
  - 占位提示起点按光标排版原点右移 3 DIP（主搜索 margin 3、动作面板 margin 13——两视图 Grid 结构不同，光标原点不同）；
  - **隐式 TextBox 模板存在 Padding 双重应用**（模板把 Padding 写进 ScrollViewer.Margin，TextBoxView 自身又应用一次），实际光标位置 = Margin + 2×Padding，凡 Padding 水平位非 0 的框光标都会穿进首字。动作面板与设置页热键框的水平间距改由 Margin 表达（Padding 水平位归 0），光标/占位/输入文字三者对齐同一起点。
  - 修复后光标与占位提示之间留有细缝（200% 屏约 2px），且占位提示与实际输入文字起点严格一致。
- 探针实测：动作面板光标精确落在设计起点（框左 10 DIP），可见间隙与主搜索一致；selftest 104 项全过。

### 升级说明

- **从 2.0.0 升级**：直接替换 exe，配置与数据（`config.json`、`custom-apps.json`、剪贴板历史等）不动。

## 2.0.0（2026-11-17）

v2 重写的首个正式版（WPF / .NET Framework 4.6.2，单 exe）。此前 rc1–rc10 均为预发布包，rc1–rc10 已全部作废；正式版内容对应 rc10，并经双屏（混合 DPI）真机验证。

### 交付物

`dist/PyTools-2.0.0-win64.zip`（PyTools.exe 503 KB + README），解压即用，无需安装。

### 功能一览（相对 v1 Electron 版的完整重写）

- 启动器：应用扫描 + 拼音首字母搜索 + 连续滚动列表；Tab 操作菜单（八项动作）；Ctrl+K 动作面板；右键「添加到 PyTools」登记与自愈。
- 剪贴板历史：事件驱动监听，文本/图片/文件记录与写回、直呼热键、隐私过滤开关。
- 工具：text-diff、regex（含 AI 生成）、cron、encoding-converter、format、vsc、ai-ocr、ai-translate、code-naming。
- 外观：明暗主题三态热切换、简洁模式；呼出动画与固定尺寸模式。

### rc4–rc10 修复的多屏呼出定位（2.0.0 最终形态）

- 呼出窗跟随**鼠标所在屏**：位置记忆**每屏一份**（键 = 设备名@整屏物理尺寸，分辨率变化自动回默认位）；无记忆或横向越界走默认位（水平居中、垂直上 1/3）。
- 全程物理像素 + 逐屏 DPI（PerMonitorV2），混合 DPI 双屏（如 200% + 100%）下位置与物理尺寸均正确。
- 跨屏 DPI 切换时窗口尺寸连期望矩形一起钉回，杜绝副屏「窗口很小且不居中」。
- 落位日志 `summon place [default|memory|memory-oob->default] key=… work=… scale=… -> x,y w=…`，排障只看这一行。

### 其他修复

- 带参数的 .lnk 启动报「不是有效的 Win32 应用程序」（193）：改用解析后的真实目标启动。
- 简洁模式暗色主题整窗发白；多行编辑区滚动条贴底；截断文本 ToolTip 显示全文；剪贴板图片 alpha 无效修复等。

### 升级说明

- **从 v1（Electron 版）升级**：v2 使用 exe 同目录存放配置（`config.json`、`custom-apps.json` 等），把 exe 放入原 v1 目录即可继承应用登记数据；全局热键、单实例、右键菜单与 v1 互斥，切换前请退出 v1。
- **从 rc 预发布版升级**：直接替换 exe。旧的全局呼出偏移会被自动作废，首次呼出为默认居中位，在各屏拖动收起后重新建立每屏记忆。
