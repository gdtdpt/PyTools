# PyTools

Windows 桌面启动器 + 常用工具集。.NET Framework 4.6.2 / WPF 单文件应用，**拷贝即用、无需安装任何运行时**，目标环境为内网脱机 Windows 10 x64。

## 安装

1. 确认已安装 .NET Framework 4.6.2 或更高（Win10 1709 及以后系统自带）。
2. 将 `PyTools.exe` 放到任意目录（建议专用目录，运行期数据文件生成在 exe 同目录）。
3. 双击运行，托盘出现图标即就绪。

首次运行在 exe 同目录生成 `config.json`（配置）等数据文件；卸载即删目录，无注册表残留（可选开启的开机自启与右键菜单除外，均可在设置中移除）。

## 呼出与基本操作

| 操作 | 默认 |
|---|---|
| 呼出启动器 | `Ctrl+Shift+Space`（设置中可改） |
| 移动选择 | `↓` / `↑`；`Ctrl+J` / `Ctrl+K` 加速；`Ctrl+N` / `Ctrl+P` 翻页 |
| 执行选中项 | `Enter` |
| 动作面板 | `Ctrl+Enter` |
| 分层退出 | `Esc` |

输入即搜：应用按名称 / 拼音首字母（如 `jtbjl` → 剪贴板记录）；输 `tools` 或 `工具` 回车进入工具列表。

## 内置工具

| 工具 | 唤醒词 | 说明 |
|---|---|---|
| 工具列表 | `tools` / `工具` | 浏览全部内置工具，支持按名称/唤醒词过滤 |
| VSCode 项目 | `vsc` | 打开最近 VSCode 项目 |
| 剪贴板记录 | `clipboard` / `剪贴板` | 剪贴板历史（文本/图片/文件），可写回、可设置独立热键 |
| 格式化 | `format` / `格式化` | JSON/XML 格式化；另有「格式化剪贴板」一键格式化并写回 |
| 常用编码转换 | `encode` / `编码` | URL/Base64/Unicode/HTML/JSON/Hex 互转 |
| Cron 表达式 | `cron` | 构造、解析与最近触发时间推算 |
| 正则测试 | `regex` / `正则` | 匹配高亮与替换预览 |
| 文件差异对比 | `diff` / `对比` | 并排比较两个文本文件，支持 GBK 等编码检测 |
| 图片文字识别 | `ocr` / `识别` | 截图或图片 → AI 提取文字 |
| AI 翻译 | `translate` / `fanyi` / `翻译` | 中英日互译，自动识别语种 |
| 代码命名 | `naming` / `var` / `命名` | 由描述生成变量/类/表名等命名建议 |

AI 类工具（识别/翻译/命名）需在设置中启用并配置模型与密钥（密钥存放于 exe 同目录 `ai-local.json`，手工放置，不入库）。

## 设置

托盘右键 → 设置，或启动器输 `settings`：

- **主题**：浅色 / 深色 / 跟随系统（即时生效）
- **简洁模式**：不透明方角、无动效（重启生效）
- **呼出热键 / 剪贴板热键**：自定义
- **开机自启 / 资源管理器右键「Add to PyTools」**：开关即生效
- **自定义应用**：把任意 exe/lnk 加入启动器

## 常见问题

- **呼出无反应**：检查是否与其他软件的热键冲突；确认托盘图标存在（进程可能在运行）。
- **换目录后数据丢失**：数据文件跟随 exe 目录，整体拷贝 exe 与同目录的 json 文件即可迁移。
- **与旧版 PyTools（Electron 版）冲突**：全局热键、单实例、右键菜单三处会互抢，同一时间只运行一个版本。
